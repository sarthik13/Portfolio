Project 01

Real-time Tracking & Monitoring Platform

The system relied on timer-based polling — every device fired API calls at fixed intervals regardless of whether data had changed. This caused backend overload, slow map rendering, and unnecessary database writes.

I redesigned the communication layer using Socket.IO and MQTT, migrating to an event-driven architecture that reacts only to real state changes. I also optimized map rendering with data caching and controlled state updates. Delivered across both Flutter mobile and Angular web.

80%Fewer API calls
40%Latency reduction

Project 02

Live Video Streaming System

The initial streaming pipeline was unstable — video feeds dropped frequently, reconnection logic was broken, and latency made real-time monitoring unusable.

I took ownership of stabilizing the entire pipeline: fixed WebRTC signaling, ICE candidate handling, and reconnection flows. Integrated AWS Kinesis Video Streams for scalable ingestion and built multi-feed switching logic. Delivered on both Flutter mobile and Angular web with the same role-based stream controls.

30%Fewer transmission issues

Project 03

BLE Device Control Platform

Marine environments with zero internet connectivity needed a reliable way to control IoT hardware from a mobile app. Bluetooth is inherently unstable across platforms — frequent disconnections, inconsistent data transfer, platform-specific quirks.

I redesigned the BLE communication layer with proper connection lifecycle handling, retry mechanisms, and structured message workflows. Built alarm management with automated and manual triggers, including emergency satellite messaging support.
